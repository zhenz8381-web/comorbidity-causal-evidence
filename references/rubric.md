# 六项质量打分细则（每项 0 / 1 / 2）

打分对象：单篇文献。评分依据**摘要 + 必要时的方法/结果段落**（先取 PMC 全文，取不到就以摘要为准并在
`note` 里注明"仅凭摘要"）。同一项拿不准时给低分，并在 note 里写清楚缺什么。

---

## S1 时序（暴露在前，结局在后）

| 分 | 判据 |
|---|---|
| 2 | 前瞻/回顾队列或注册研究，**明确排除基线已患结局病**，有随访人年、发病密度或明确的先后顺序（含自身对照病例系列 SCCS、landmark analysis） |
| 1 | 有随访但排除基线病例的做法描述不清；或病例对照研究但暴露时间窗明确 |
| 0 | 横断面研究、单纯患病率比较、无时间信息（**这类研究不得给因果结论**） |

关键词提示：incident / newly diagnosed / baseline-free / follow-up / person-years / preceded / subsequent / lag period。

---

## S2 疾病表型（精准、可重复）

| 分 | 判据 |
|---|---|
| 2 | ICD-9/10 或 Read/ICPC 编码、全国登记库（如瑞典 NPR、丹麦 DNPR、UK Biobank 算法定义）、或公认诊断标准（如 Rome IV、ACR 标准），且报告了验证/阳性预测值 |
| 1 | 电子病历诊断或医生诊断，但无编码细节；或有编码但未验证 |
| 0 | 仅自报问卷单一条目、单一症状、无定义的"病史" |

---

## S3 分组（区分单纯患病 vs 共病）

| 分 | 判据 |
|---|---|
| 2 | 明确分出「单纯 A」「单纯 B」「A+B 共病」三组（或交互分层），比较了共病组相对两单病组的额外风险 |
| 1 | 只比较了「有 A」vs「无 A」的 B 风险，未单独分析共病组 |
| 0 | 只报告共病患病率，没有对照或分层 |

---

## S4 协同交互检验

| 分 | 判据 |
|---|---|
| 2 | 报告了相加或相乘交互：RERI、AP、S、或相乘项 P 值，并讨论了超可加性/协同效应 |
| 1 | 只做了分层分析（各层效应量不同），未正式检验交互 |
| 0 | 完全没有交互或分层分析 |

---

## S5 偏倚控制与"因果 vs 相关"的鉴别（本项最关键，A 级必须 ≥ 1）

分两部分，取较低者：

**偏倚控制**

| 分 | 判据 |
|---|---|
| 2 | 人群对照（排除 Berkson）；且校正了就诊频率/筛查强度（如用阴性对照结局、门诊次数校正、healthcare utilization 匹配）；且校正了主要共同危险因素 |
| 1 | 仅校正人口学与常见危险因素，未处理 Berkson 或检测偏倚 |
| 0 | 医院对照 + 未校正就诊强度；或无任何混杂校正 |

**因果 vs 相关鉴别（直接影响 direction 判定）**

| 分 | 判据 |
|---|---|
| 2 | 用了孟德尔随机化、阴性对照结局/暴露、自身对照设计、家族/同胞设计，或做了遗传相关（LDSC/GWAS 相关）与 MR 的区分讨论 |
| 1 | 仅在讨论里提到"不能排除共同危险因素/遗传因素"，无具体分析 |
| 0 | 完全未讨论，把相关当因果 |

---

## S6 结论尺度与价值

| 分 | 判据 |
|---|---|
| 2 | 结论克制（用"支持/提示/与…一致"而非"证明"），明确写出局限（残余混杂、反向因果、普适性），且给出临床或机制层面的可执行价值（筛查建议、用药警示、通路解释） |
| 1 | 结论基本克制但缺少局限讨论，或价值表述空泛 |
| 0 | 措辞过度（"proves causality"）、无局限、无价值 |

---

## 阈值与判定

- 总分 = S1+…+S6，满分 12。
- **A 级**：≥ 9 且 S1 ≥ 1 且 S5 ≥ 1，方向明确。
- **B 级**：6–8 且 S1 ≥ 1。
- **C 级**：S1 = 0（无时序信息），或 S5 显示无法排除共同危险因素/遗传相关 → 一律降级为"仅相关"。
- **D 级**：L0 未过或总分 ≤ 5，剔除。

## 方向判定的证据优先级

1. MR / 遗传工具变量研究（方向性最强）
2. 前瞻队列（暴露在前、排除基线病例）
3. SCCS / 自身对照病例系列
4. 有明确暴露时间窗的病例对照
5. 双向都做了的设计（能同时报告 A→B 与 B→A）
6. 横断面 → **只能判"仅相关"**

双向都做了却只有一个方向显著，是最有价值的结论，要在 summary 里单独点出。
